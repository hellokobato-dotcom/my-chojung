## 🚀 사용 방법

### 1. 시스템 접속
웹 브라우저에서 다음 URL로 접속:
```
https://8000-i8yzqyyo33zg0tqj0s5vq-ea026bf9.sandbox.novita.ai/v2026-final.html
```

### 2. 직원 등록
1. 상단의 **"직원 등록"** 버튼 클릭
2. 필수 정보 입력:
   - 이름, 부서, 전화번호
   - 고용 형태 (일용직/정규직/계약직)
   - 시급
   - 입사일
3. 선택 정보 입력:
   - 사진, 사번, 직급
   - 은행 및 계좌번호
   - 메모
4. **"저장"** 클릭

### 3. 급여 지급
1. 직원 카드에서 **"수정/급여지급"** 버튼 클릭
2. 근무 시간 입력
3. 실시간 계산 미리보기 확인:
   - 기본급
   - 4대보험 공제 내역 (계산식 포함)
   - 실지급액
   - 사업용/개인 계좌 분할
4. **"저장 및 급여지급"** 클릭

### 4. 급여 내역 조회
1. 상단 탭에서 **"급여 내역"** 클릭
2. 지급일, 직원명, 금액 등 확인
3. **"👁"** 버튼으로 상세 내역 확인

### 5. 엑셀 다운로드
1. 상단의 **"엑셀 다운로드"** 버튼 클릭
2. CSV 파일 자동 다운로드
3. 엑셀에서 열어서 편집 가능

## 🧮 계산기 함수 사용법

### JavaScript 함수 예제

시스템에 내장된 계산 함수를 사용할 수 있습니다:

```javascript
// 2026년 4대보험 계산 함수
function calculate2026SocialInsurance(monthlySalary, employmentType) {
    // monthlySalary: 보수월액 (숫자)
    // employmentType: '일용직', '정규직', 또는 '계약직'
    
    if (employmentType === '일용직') {
        const employment = Math.round(monthlySalary * 0.009);
        return {
            nationalPension: 0,
            healthInsurance: 0,
            longTermCare: 0,
            employmentInsurance: employment,
            total: employment
        };
    }
    
    // 정규직/계약직
    const pensionSalary = Math.max(400000, Math.min(monthlySalary, 6370000));
    const nationalPension = Math.round(pensionSalary * 0.0475);
    const healthInsurance = Math.round(monthlySalary * 0.03595);
    const longTermCare = Math.round(healthInsurance * 0.1314);
    const employmentInsurance = Math.round(monthlySalary * 0.009);
    
    return {
        nationalPension,
        healthInsurance,
        longTermCare,
        employmentInsurance,
        total: nationalPension + healthInsurance + longTermCare + employmentInsurance
    };
}

// 사용 예제
const result = calculate2026SocialInsurance(3000000, '정규직');
console.log(`공제액 합계: ${result.total.toLocaleString()}원`);
// 출력: 공제액 합계: 291,521원
```

### Node.js 모듈 사용

## 🔍 특이사항 및 주의사항

### 국민연금 상한/하한
- **상한**: 보수월액이 6,370,000원을 초과하더라도 6,370,000원을 기준으로 계산
- **하한**: 보수월액이 400,000원 미만이더라도 400,000원을 기준으로 계산

### 장기요양보험
- 건강보험료의 13.14%로 계산
- 건강보험료가 먼저 계산된 후 적용

### 일용직 특례
- 일용직 근로자는 국민연금, 건강보험, 장기요양보험이 면제됩니다.
- 고용보험(0.9%)만 부과됩니다.

### 사업용/개인 계좌 분할
- 실지급액이 713,520원을 초과하는 경우:
  - 사업용 계좌: 713,520원
  - 개인 계좌: 나머지 금액
- 713,520원 이하인 경우:
  - 개인 계좌로만 지급

## 🐛 문제 해결

### 데이터가 보이지 않는 경우
1. 브라우저 캐시 삭제
2. F5 새로고침
3. 샘플 데이터 자동 생성 확인

### 계산이 이상한 경우
1. 입력값 확인 (숫자만 입력)
2. 고용 형태 확인 (일용직/정규직/계약직)
3. 콘솔 로그 확인 (F12 > Console)

### 엑셀 다운로드가 안 되는 경우
1. 브라우저 팝업 차단 해제
2. 다운로드 폴더 확인
3. 다른 브라우저 시도

## 🎯 소개

**초정 가계부 직원 관리 시스템**은 중소기업을 위한 통합 인건비 관리 솔루션입니다.

### 주요 특징
- ✅ **직관적인 UI/UX** - 사용하기 쉬운 인터페이스
- ✅ **자동 급여 계산** - 4대보험 공제액 자동 계산
- ✅ **급여 이력 관리** - 직원별 급여 지급 이력 추적
- ✅ **엑셀 내보내기** - 데이터 백업 및 외부 활용
- ✅ **반응형 디자인** - PC, 태블릿, 모바일 지원
- ✅ **실시간 통계** - 인건비 현황 한눈에 파악

---

## 🚀 주요 기능

### 1. 직원 관리
- 직원 정보 등록/수정/삭제
- 직원 사진 업로드
- 부서별 직원 관리
- 고용 형태 관리 (일용직/상용직)
- 입사/퇴사 관리

### 2. 급여 관리
- 급여 자동 계산 (시급 × 근무시간 또는 월급)
- 4대보험 공제액 자동 계산
  - **일용직**: 고용보험 0.9%
  - **상용직**: 국민연금 4.5%, 건강보험 3.545%, 장기요양보험 12.95%, 고용보험 0.9%
- 사업용/개인용 계좌 자동 분배 (기준: 713,520원)
- 급여 지급 이력 관리

### 3. 통계 및 리포트
- 실시간 통계 대시보드
- 월별 인건비 집계
- 직원별 급여 이력
- 엑셀 내보내기 기능

### 4. 검색 및 필터링
- 직원명, 부서, 연락처로 검색
- 재직 상태 필터링
- 고용 형태 필터링
- 급여 지급 연월 필터링

## ✨ 개선 사항 (v2.0)

### 사용자 편의성
1. **급여 이력 관리**
   - 한 직원의 모든 급여 지급 내역을 모달에서 확인
   - 지급일, 근무시간, 금액 등 상세 정보 표시

2. **탭 기반 UI**
   - 직원 목록과 급여 지급 내역을 탭으로 분리
   - 더 깔끔하고 직관적인 화면 구성

3. **향상된 검색/필터링**
   - 다중 조건 필터링 지원
   - 부서, 고용형태, 재직상태 동시 필터링 가능

4. **실시간 급여 계산**
   - 근무시간 입력 시 즉시 급여 계산
   - 공제액 상세 내역 표시
   - 사업용/개인용 계좌 자동 분배

5. **엑셀 내보내기**
   - 직원 목록 엑셀 다운로드
   - 급여 지급 내역 엑셀 다운로드
   - 한글 인코딩 지원 (UTF-8 BOM)

### 데이터 관리
1. **분리된 테이블 구조**
   - `employees` 테이블: 직원 기본 정보
   - `payments` 테이블: 급여 지급 내역
   - 더 효율적인 데이터 관리 및 조회

2. **데이터 무결성**
   - 필수 필드 유효성 검증
   - 전화번호 형식 검증
   - 급여 계산 정확도 향상

### UI/UX 개선
1. **반응형 디자인**
   - 모바일, 태블릿, PC 모두 최적화
   - 터치 친화적 버튼 크기

2. **직관적인 아이콘**
   - Font Awesome 6 아이콘 사용
   - 시각적으로 명확한 기능 표시

3. **사용자 피드백**
   - 성공/실패 메시지 표시
   - 확인 대화상자로 실수 방지
   - 로딩 상태 표시

4. **키보드 단축키**
   - `Esc`: 모달 닫기
   - `Ctrl + S`: 저장

## 📖 사용 방법

### 1. 직원 등록

1. **"직원 등록" 버튼 클릭**
2. **기본 정보 입력**
   - 이름 (필수)
   - 부서 (필수) - 자동완성 지원
   - 연락처 (필수) - 형식: 010-0000-0000
   - 사진 (선택) - 최대 5MB

3. **고용 정보 입력**
   - 고용 형태 선택 (일용직/상용직)
   - 시급 또는 월급 입력
   - 입사일 (필수)
   - 계좌번호 (선택)

4. **저장 버튼 클릭**

### 2. 급여 지급

#### 방법 1: 직원 목록에서 직접 지급
1. 직원 목록에서 **"급여" 버튼** 클릭
2. 급여 정보 입력
   - 지급일
   - 근무시간
3. 자동 계산 확인
   - 기본급
   - 공제액 상세
   - 최종 지급액
4. **저장 버튼** 클릭

#### 방법 2: 직원 수정 화면에서 지급
1. 직원 목록에서 **수정 아이콘** 클릭
2. 급여 지급 정보 섹션에서 정보 입력
3. 저장

### 3. 급여 이력 확인

1. 직원 목록에서 **수정 아이콘** 클릭
2. 화면 하단 **"급여 지급 이력"** 섹션 확인
3. 각 이력 카드에서 상세 정보 확인
   - 지급일
   - 근무시간
   - 기본급, 공제액, 지급액
   - 신고여부

### 4. 검색 및 필터링

#### 직원 목록 필터링
- **재직 상태**: 전체/재직/퇴직
- **부서**: 등록된 부서 목록
- **고용 형태**: 전체/일용직/상용직
- **검색**: 이름, 연락처로 실시간 검색

#### 급여 내역 필터링
- **연도**: 지급 연도 선택
- **월**: 지급 월 선택 (1-12월)
- **검색**: 직원 이름으로 검색

### 5. 엑셀 내보내기

1. **"엑셀 다운로드" 버튼** 클릭
2. 현재 탭의 데이터가 다운로드됨
   - 직원 목록 탭: 직원 정보
   - 급여 내역 탭: 급여 지급 내역
3. CSV 파일로 저장 (엑셀에서 열기 가능)

### 6. 직원 삭제

1. 직원 목록에서 **휴지통 아이콘** 클릭
2. 확인 대화상자에서 **확인**
3. 관련된 모든 급여 내역도 함께 삭제됨

⚠️ **주의**: 삭제된 데이터는 복구할 수 없습니다.

## 🔧 기능 상세 설명

### 급여 자동 계산 로직

#### 1. 기본급 계산
```
일용직: 기본급 = 시급 × 근무시간
상용직: 기본급 = 월급
```

#### 2. 공제액 계산

**일용직**
```
고용보험 = 기본급 × 0.9%
```

**상용직**
```
국민연금 = 기본급 × 4.5%
건강보험 = 기본급 × 3.545%
장기요양보험 = 건강보험 × 12.95%
고용보험 = 기본급 × 0.9%

총 공제액 = 국민연금 + 건강보험 + 장기요양보험 + 고용보험
```

#### 3. 최종 지급액
```
최종 지급액 = 기본급 - 총 공제액
```

#### 4. 계좌 분배 (자동)
```
기준 금액: 713,520원

지급액 ≤ 713,520원:
  - 사업용 계좌: 전액
  - 개인용 계좌: 0원

지급액 > 713,520원:
  - 사업용 계좌: 713,520원
  - 개인용 계좌: 지급액 - 713,520원
```

## 🐛 문제 해결

### 1. 데이터가 로드되지 않음
**원인**: API 서버 연결 문제
**해결방법**:
- 브라우저 콘솔(F12)에서 에러 메시지 확인
- API 엔드포인트 확인
- 서버 상태 확인

### 2. 사진 업로드가 안 됨
**원인**: 파일 크기 초과 또는 형식 오류
**해결방법**:
- 이미지 파일 크기를 5MB 이하로 줄이기
- JPG, PNG, GIF 형식만 지원
- 다른 브라우저에서 시도

### 3. 급여 계산이 이상함
**원인**: 입력값 오류
**해결방법**:
- 시급/월급이 올바르게 입력되었는지 확인
- 근무시간이 소수점 포함 올바른 숫자인지 확인
- 고용 형태가 정확히 선택되었는지 확인

### 4. 엑셀 다운로드 시 한글 깨짐
**원인**: 인코딩 문제
**해결방법**:
- 파일을 메모장으로 열고 다른 이름으로 저장 (UTF-8 BOM)
- 또는 최신 버전의 Excel 사용

### 5. 모바일에서 화면이 이상함
**원인**: 브라우저 호환성 문제
**해결방법**:
- 최신 버전의 Chrome, Safari 사용
- 화면을 세로 방향으로 회전
- 브라우저 캐시 삭제
